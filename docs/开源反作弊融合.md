# 开源反作弊融合说明

本文档记录 Aluer ServerGuard 融合开源 Minecraft 反作弊项目的检测算法、来源与许可证合规。

## 一、许可证

本项目已采用 **GNU General Public License v3.0**（见根目录 `LICENSE`），与
[GrimAC](https://github.com/GrimAnticheat/Grim)、[NoCheatPlus](https://github.com/NoCheatPlus/NoCheatPlus)、
[Kauri](https://github.com/funkemunky/Kauri) 等 GPL 开源反作弊的许可证兼容，
因此可以直接合并其检测算法代码。

## 二、融合方式

Aluer 采用「外部引擎 + 游戏内 Agent」双体架构，检测服务接收 Agent 采集后序列化的
结构化数据（坐标、角度、时间戳、数据包类型），而非 Bukkit 事件或 PacketEvents 数据包对象。

因此合并开源代码时，将其「数据包事件驱动的检测算法」翻译为「结构化数据方法调用驱动的
等价状态机检测」：**检测逻辑保持一致，仅适配输入接口与包结构**（统一归入 `com.aluer.anticheat`）。

## 三、已合并的检测算法（拉取源码翻译合并）

### GrimAC BadPackets 系列（已合并至 `AntiBadPacketsService`）

| Grim Check | 检测内容 | Aluer 方法 |
| --- | --- | --- |
| BadPacketsA | 重复 held item slot | `checkHeldItemSlot` |
| BadPacketsC | 未睡觉却发送起床动作 | `checkLeaveBed` |
| BadPacketsD | pitch 越界（>90 或 <-90） | `checkRotation` |
| BadPacketsE | 连续移动包无位置更新 | `checkMovementUpdate` |
| BadPacketsF | 重复 sprint 状态 | `checkSprintAction` |

### NoCheatPlus fight 系列（已合并）

| NCP Check | 检测内容 | Aluer 服务 |
| --- | --- | --- |
| fight/NoSwing | 挥臂标志 + VL 累积/衰减 | `AntiNoSwingService`（对齐源码重写） |
| fight/GodMode | 受击后生命值不下降（无敌） | `AntiGodModeService` |
| fight/FastHeal | 回血间隔小于合法间隔 | `AntiFastHealService` |

## 四、借鉴检测维度（独立实现）

| 服务 | 借鉴来源 | 检测内容 |
| --- | --- | --- |
| `AntiFastLadderService` | NCP FastLadder/Ascend | 攀爬状态单 tick 上升超速 |
| `AntiNoWebService` | NCP NoWeb | 蜘蛛网内水平位移超速 |
| `AntiAimService` | Kauri Aim / Grim 旋转预测 | 头部瞬间转向 snap |

## 五、主机安全扩展

| 服务 | 包路径 | 检测内容 |
| --- | --- | --- |
| `ProcessSecurityService` | `com.aluer.defense` | 挖矿木马 / 反弹 shell / 可疑路径进程扫描 |
| `FileSecurityScannerService` | `com.aluer.defense` | webshell / 后门脚本 / 可疑文件扫描 |

## 六、后续可合并维度

- Grim 其余 BadPackets（G–Z）及 Reach / Timer / Velocity 等预测式检测（需先移植移动模拟引擎）。
- NCP 的 FastBow / GodMode 完整版（NMS 无敌 tick 校验）/ FastHeal buffer 完整逻辑。
